# 🐧 Linux Administration — Hands-on Practice

**By Pavan Kushwaha**

This repository contains my hands-on Linux administration practice using **Ubuntu Linux**, with practical work performed in **VMware and VirtualBox** environments.

The goal of this practice was to understand Linux basics, system management, services and processes from a Cloud Engineer / DevOps perspective.

---

## 🖥️ Practice Environment

- **OS:** Ubuntu Linux
- **Virtualization:** VMware · VirtualBox
- **Focus:** Linux Administration & System Management

---

## 📚 Topics Covered

### 1. Basic Linux Commands
- Navigating directories
- Working with files and directories
- Viewing and managing files
- Basic system-related commands

### 2. Linux Permissions
- `chmod`
- `chown`
- File and directory permissions
- Understanding Linux permission concepts

### 3. systemctl & Service Management
- Understanding Linux services
- Starting and stopping services
- Checking service status
- Managing services using `systemctl`

### 4. Process Management
- Understanding running processes
- Viewing processes
- Managing process priority
- Using `nice` and `renice`
- Basic process management
